---

## 📱 Что это?

ADB Painter — программа для автоматического рисования любых изображений в приложениях на Android (например, в играх-рисовалках типа Gartic Phone, Skribbl.io и т.д.) используя технологию ADB (Android Debug Bridge).

## ✨ Возможности

- 🖼️ Загрузка любых изображений (PNG, JPG, BMP)
- 🎨 Обнаружение контуров с настраиваемой чувствительностью
- 📍 Визуальное позиционирование — перетаскивайте картинку мышью
- 📸 Захват экрана телефона для точной калибровки
- ⚡ Быстрое batch-рисование
- 🎛️ Настройка скорости и детализации

## 🚀 Быстрый старт

### 1. Подготовка телефона
1. Включите **Режим разработчика** (7 тапов по номеру сборки)
2. В настройках разработчика включите **Отладка по USB**
3. Подключите телефон USB кабелем к компьютеру

### 2. Запуск программы
1. Скачайте `ADB_Painter.exe` из [Releases](../../releases)
2. Запустите программу
3. Нажмите **Connect ADB**
4. Загрузите изображение (**Load Image**)
5. Перетащите картинку на нужное место
6. Нажмите **START DRAWING**

## 🎮 Интерфейс

| Элемент | Описание |
|---------|----------|
| **Connect ADB** | Подключение к телефону |
| **Capture Screen** | Скриншот экрана телефона для калибровки |
| **Load Image** | Загрузить изображение |
| **Center Image** | Центрировать картинку |
| **Edge Sensitivity** | Чувствительность контуров (меньше = больше линий) |
| **Detail** | Детализация (больше = точнее, но медленнее) |
| **Speed** | Скорость рисования (ms на линию) |
| **Remove Background** | Удаление фона (требует GPU/время) |

## ⚙️ Требования

- Windows 10/11
- Android устройство с USB Debug
- USB кабель
